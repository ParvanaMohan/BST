Learn the fundamentals
Quick reference

        

          
A Binary Search Tree (BST) is a binary tree where every value in the left subtree is smaller than its node, and every value in the right subtree is larger. This version stores unique values.

          
OperationAverage caseWorst case

            
SearchO(log n)O(n)
InsertO(log n)O(n)
DeleteO(log n)O(n)
Min / maxO(log n)O(n)
TraversalO(n)O(n)

          
Here, n is the number of nodes. Average-case lookup is logarithmic when the tree is reasonably balanced; inserting already sorted values into a plain BST can create a chain and make operations linear.
